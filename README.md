# Office SDK Cluster · 石墨办公文档中台私有部署

简体中文 · [English](README.en.md)

在企业环境中部署石墨文档中台，通过 API 和 Web 编辑器为已有的 OA、合同、档案等系统接入 **Office 文件预览、多人协同编辑和格式转换**。用户在业务页面打开文档，业务系统管理用户身份和文件权限。

**[产品介绍](docs/product.md) · [接口接入](docs/integration.md) · [私有部署](docs/deployment.md) · [运行维护](docs/operations.md)**

## 快速开始

**目标是在合同详情页打开一份协同文档。** 经办人修改内容后重新打开，修改仍然可见。审批人用只读账号打开同一份文件，可以阅读，无法修改。

- **还没有中台环境**，先走单机部署与验收，拿到可访问的中台地址。[私有部署指南](docs/deployment.md)
- **已有可用环境**，配置应用凭证和业务回调，再由业务后端创建文件，前端嵌入编辑器。[协同编辑接入指南](docs/integration.md)

## 按场景选接入方式

| 你要做的事 | 接入方式 |
| --- | --- |
| 让用户在审批页查看已上传的 Office 附件 | 保留业务存储中的原件，按用户权限提供预览 |
| 让多人在合同详情页修订同一份文件 | 创建协同文件，用同一个 `fileId` 为不同用户打开编辑器 |
| 把已有合同导入编辑，再将定稿归档 | 发起导入、导出任务，任务成功后将结果交给下一环节 |

[查看三个场景的接入方式和验收要点](docs/product.md)
